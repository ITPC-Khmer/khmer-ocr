HOW TO USE https://ai.sothea.us — OLLAMA AI SERVER
===================================================
Ollama running on the khmer-ocr server (152.42.210.186), exposed via
nginx + Let's Encrypt at https://ai.sothea.us.
Installed model: gemma2:9b (CPU only, 4 vCPU — expect slow generation).

WARNING: the endpoint is PUBLIC with NO authentication. Anyone who
finds the URL can run generations or pull/delete models. Consider
adding nginx basic auth or an IP allowlist.

NOTE: requests proxied through Cloudflare are cut off at ~100 seconds.
Long generations should use stream:true (streaming keeps the
connection alive), or call the server directly from inside the box
(http://localhost:11434).

------------------------------------------------------------
1. CHECK STATUS / LIST MODELS
------------------------------------------------------------
curl https://ai.sothea.us/                # "Ollama is running"
curl https://ai.sothea.us/api/tags        # installed models

------------------------------------------------------------
2. GENERATE (one-shot prompt)
------------------------------------------------------------
curl https://ai.sothea.us/api/generate -d '{
  "model": "gemma2:9b",
  "prompt": "Why is the sky blue?",
  "stream": false
}'
# Response JSON: {"response": "...", ...}
# stream:true (default) sends line-by-line JSON chunks instead —
# recommended through Cloudflare, see note above.

------------------------------------------------------------
3. CHAT (multi-turn)
------------------------------------------------------------
curl https://ai.sothea.us/api/chat -d '{
  "model": "gemma2:9b",
  "messages": [
    {"role": "user", "content": "សួស្តី! ជួយប្រែសម្រួលអត្ថបទនេះ..."}
  ],
  "stream": false
}'

------------------------------------------------------------
4. PYTHON EXAMPLE
------------------------------------------------------------
import requests

r = requests.post("https://ai.sothea.us/api/generate", json={
    "model": "gemma2:9b",
    "prompt": "Fix OCR errors in this Khmer text: ...",
    "stream": False,
    "options": {"temperature": 0},
}, timeout=600)
print(r.json()["response"])

# Or with the official client:  pip install ollama
from ollama import Client
client = Client(host="https://ai.sothea.us")
print(client.generate(model="gemma2:9b", prompt="hello").response)

------------------------------------------------------------
5. USE FROM KHMER OCR APP
------------------------------------------------------------
The OCR API (https://ocr.sothea.us) uses this server for text
correction. Configure in /opt/khmer-ocr/.env:
  OLLAMA_URL=https://ai.sothea.us   # or http://localhost:11434 (faster, no Cloudflare limit)
  OLLAMA_MODEL=gemma2:9b
  OLLAMA_CORRECT=1                  # currently 0 (disabled) — server has only 4 vCPU
Then: systemctl restart khmer-ocr

------------------------------------------------------------
6. MANAGE MODELS (on the server via SSH)
------------------------------------------------------------
ollama list                  # installed models
ollama pull <model>          # install a model
ollama rm <model>            # delete a model
systemctl status ollama      # service status
journalctl -u ollama -f      # logs
